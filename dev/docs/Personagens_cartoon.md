# Personagens no estilo cartoon (4 imagens)

**Como usar:** em cada pedido, anexe duas referências: um print de um dos vídeos do jogo de referência que mostre bem um personagem, e uma imagem de monstro já aprovada (para manter o mesmo acabamento). Mande as imagens na ordem abaixo.

Se o Gemini mudar a ordem, o número de figuras ou escrever nomes, me avise e eu ajusto o recorte.

---

## 1) Herói (menino), 4 vistas
```
Use the art style of the attached reference images: chibi 3D cartoon, like a cute mobile monster-collecting game. Character turnaround sheet of ONE ORIGINAL young boy trainer hero (not based on any existing franchise), super-deformed chibi proportions: very big round head about the same size as the body, short stubby limbs, big shiny expressive eyes, small nose, rounded soft shapes everywhere, smooth glossy 3D toy-like shading, bright saturated colors, thick soft dark outline. Outfit: spiky brown hair, orange cap worn backwards, teal short jacket over a white shirt, small yellow backpack, dark blue shorts, red sneakers.
4 poses of the SAME character, evenly spaced in ONE row with wide gaps, same size and same scale, full body, standing on the same ground line. Left to right:
1) front view, neutral happy pose.
2) 3/4 view facing right.
3) side view facing right, mid walking step.
4) back view.
Crisp clean sharp edges, fully opaque. Background: solid flat pure magenta (#FF00FF), perfectly uniform. NO shadows, NO glow, NO smoke, NO text, NO labels.
```
